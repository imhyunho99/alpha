# 추세 주식 전략 — 지금 규칙의 근거와 한 달 뒤 튜닝 계획

작성 2026-10-13. 실계좌 `my-kb`(새 돈 1,063,707원만 운용, 기존 4종목은 안 건드림).

## 1. 지금 전략은 어떻게 나왔나

| 시기 | 시도 | 결과 | 남긴 교훈 |
|---|---|---|---|
| 8월 | 머신러닝 예측 모델(76피처 앙상블) | 5일 예측은 동전 던지기(AUC 0.50), 20일은 약한 신호 | 정확도 100%·수익 +3,676% 같은 숫자는 전부 평가 실수였다 |
| 9월 | 뉴스 감성 매매(FinBERT) | 1년 백테스트 +12.7% vs 그냥 보유 +92% | 뉴스 타이밍은 가치를 더하지 못했다 |
| 10/10 | 주식/채권 배분(SPY 60 / IEF 40) | 20년 CAGR 10.2%, MDD 13.2% | 안정적이지만 "ETF만 살 거면 내가 하지"(사용자) |
| 10/11 | **SPY 70% + S&P 500 모멘텀 상위 10종목 각 3%** | 아래 표 | 현재 운용 중 |

**모멘텀(추세) 규칙**: 매달 S&P 500 종목의 "12개월 전 → 1개월 전" 수익률 상위 10종목을 산다
(Jegadeesh-Titman 1993. 최근 1개월을 빼는 건 단기 되돌림을 피하려고). 위성 종목은 산 값보다 20% 빠지면 판다.

검증(`scripts/momentum_study.py`, 원화, 비용 0.3%, 2006-07 ~ 2026-09, **그 달에 실제로 S&P 500에 있던 종목만**):

| | CAGR | MDD |
|---|---:|---:|
| SPY 그냥 보유 | 13.3% | 22.3% |
| 모멘텀 10종목 단독 | 11.9% | 49.3% |
| **SPY 70 + 모멘텀 30 (지금)** | 13.3% | 29.3% |

(손절 -20%와 실계좌 리밸런싱 밴드를 넣어 일별로 다시 돌리면 12.8% / 30.5% — 5절 B0.)

솔직한 평가: 20년 수익은 SPY와 같고 낙폭은 더 크다. 후반 10년만 보면 연 +1.1%p 앞섰다.
"주식을 직접 고르되 SPY보다 크게 나빠지지 않는 선"으로 위성을 30%에 묶은 것이다.
오늘 구성 종목으로 과거를 돌리면 모멘텀이 최근 5년 연 80%로 나오는데, 이는 나중에 편입될 급등주를 미리 아는 착시라 쓰지 않았다.

## 2. 앞으로 한 달(10/13 ~ 11/초): 그대로 운용, 실행만 본다

한 달 성과로는 전략의 좋고 나쁨을 판단할 수 없다. 위성 30%의 월 변동은 약 ±2.5%(계좌 기준)인데,
기대하는 개선폭은 연 0.5%p 안팎이다. 이 차이를 실운용으로 가려내려면 수십 년이 필요하다.
그래서 한 달 동안은 **"백테스트대로 실제로 사고팔리는가"**만 확인한다.

| 확인 항목 | 기준 | 어디서 |
|---|---|---|
| 주문 체결 | 거절·미체결 0건(장 시간·1,000원 단위·소수점 불가 종목) | 서버 로그, 미러 기록 |
| 중복 매수 | 같은 종목 하루 2번 매수 0건 | 미러 기록 |
| 목표 비중 추종 | SPY 70% ±7%p, 위성 각 3% ±1%p | 내 계좌 탭 |
| 11월 첫 교체 | 빠진 종목 매도 → 새 종목 매수가 하루 10건 한도 안에서 이틀 안에 끝남 | 11/3~4 밤 |
| 비용 | 매매·환전 비용이 백테스트 가정(0.3%) 이하 | KB 체결 내역 |

## 3. 튜닝할 때 쓰는 손실함수

```
L = -(전략 CAGR - SPY CAGR) + 0.5 × max(0, 전략 MDD - SPY MDD)        (원화, 비용 차감, 작을수록 좋다)
```

- **왜 SPY 대비인가**: 이 전략의 대안은 "SPY를 그냥 사는 것"이다. 그보다 더 벌지 못하면 직접 고를 이유가 없다.
- **왜 낙폭 벌점인가**: 같은 수익이면 덜 빠지는 쪽이 낫다. 다만 SPY보다 깊게 빠진 만큼만 벌점을 준다.
  0.5는 "낙폭 2%p를 수익 1%p와 바꾼다"는 뜻이다. 사용자가 "다 잃어도 된다"고 했던 위험 성향에 맞춰 낮게 잡았다.
- **왜 샤프비율이 아닌가**: 변동성은 사용자가 체감하는 손실(최대 낙폭)과 다르다. 또 코어가 70%라 샤프 차이가 작아 판별력이 낮다.
- **코어 비율(70%)은 튜닝하지 않는다**: 이 손실함수로는 코어를 늘릴수록 항상 좋다(위성 0% = SPY = L 0).
  비율은 성과가 아니라 "얼마나 직접 고르고 싶은가"의 선택이라 사용자가 정한다.

## 4. 채택 기준 (셋 다 통과해야 바꾼다)

1. **두 시대 모두 개선**: 전반(2006-07 ~ 2016-06)과 후반(2016-07 ~ 끝) 모두 L이 지금 전략(B0)보다 작다.
2. **꾸준함**: 5년 창(매년 6월에 시작, 16개)의 60% 이상에서 B0를 이긴다.
3. **운이 아님**: B0 대비 월 초과수익의 Deflated Sharpe Ratio(Bailey & López de Prado 2014)가 0.95 이상이다.
   시도 횟수는 이 파일 후보 9개에 이전에 본 5개를 더해 14로 보정한다. 후보를 늘리면 이 숫자도 늘린다.

시뮬레이션은 실계좌 규칙을 따른다. 매달 목표 비중으로 맞추되, 보유 종목은 목표에서 max(10%, 계좌 1%) 넘게 벗어날 때만 맞춘다.
손절은 일별 종가로 판정하고, 판 몫은 그 달 남은 기간 동안 SPY에 둔다.

읽는 법:
- **바로 채택할 것은 없다.** 가장 나은 두 후보도 "운으로도 나올 수 있는 차이"를 넘지 못했다(DSR 0.31, 0.07).

  후반 10년에서는 B0보다 근소하게 뒤졌다. 2008 낙폭이 SPY와 같았다는 것은 위기 때 위성이 시장처럼 움직였다는 뜻이다.
- 탈락 후보는 11월에 다시 돌리더라도 판정이 바뀔 가능성이 낮다.

## 6. 11월 초 튜닝 절차

1. 10월 실행 점검(2절 표)을 통과했는지 확인한다. 실패한 항목이 있으면 튜닝보다 그것부터 고친다.
2. `PYTHONPATH=. python scripts/momentum_tuning.py --refresh`로 10월 자료를 넣어 다시 판정한다.
   후보와 손실함수는 바꾸지 않는다. 바꾸면 시도 횟수를 늘려 DSR을 다시 보정한다.
3. 판정
   - 기준 셋 다 통과한 후보가 있으면 → 사용자에게 보고하고 승인을 받아 켠다.
   - "관찰" 후보만 있으면 → 기본은 유지한다. 사용자가 위험·성향 근거로 고르고 싶으면 아래 스위치로 켤 수 있다.
4. 켜는 방법(코드는 준비됨, 기본값은 지금 규칙 그대로): `my-kb` 설정에 다음을 넣는다.
   - `"momentum_score": "resid"` → 잔차 모멘텀. 바꾼 다음 달 선정부터 적용되고, 이미 정한 달은 그대로 둔다.
   - `"momentum_stop_loss": null` → 손절 끔. 숫자를 넣으면 그 비율로 손절한다.
   - 다음 달 1일 전에 바꾸면 그 달 첫 교체부터 적용된다. 교체 매매는 평소 한 달 치와 비슷하다(위성 30% 중 바뀌는 종목만).

## 7. 한계

- 상장폐지돼 시세가 없는 옛 종목은 빠진다(구성 종목 976개 중 677개만 시세 있음). 모멘텀이 망한 종목을 골랐던 경우가 빠지므로, 모든 후보의 성과가 조금씩 부풀려진다.
- 업종 분류는 지금 기준이다. 시세가 없는 종목은 자기 자신을 한 업종으로 쳤다.
- 일별 손절은 종가 기준이다. 실계좌는 장중 시세로 판정하므로 결과가 조금 다를 수 있다.
- 비용 0.3%는 KB 소수점 수수료 + 환전 스프레드 추정치다. 2절에서 실측해 다르면 다시 돌린다.
