# 뉴스 기반 매매 — 조사 결과와 실험 설계 (2026-09-27)

deep-research 워크플로(검색 5갈래 → 출처 15개 → 주장별 3표 적대적 검증)로 조사했다.

## 검증을 통과한 결과

| # | 결과 | 확신 | 출처 |
|---|---|---|---|
| 1 | 하루치로 모은 뉴스 감성은 1~2일(분위 스프레드 0.17%→0.04%)을, 주간으로 모은 감성은 최대 13주를 예측한다 | 높음 (3-0) | Heston & Sinha, FEDS 2016-048 / FAJ 73(3) 2017 |
| 2 | 비대칭: 호재는 약 1주 안에 반영되고, 악재는 최대 한 분기 동안 추가 하락을 예고한다(주간 시차 1~6, 10에서 유의). GPT-4 연구도 숏 쪽 Sharpe 2.01 대 롱 0.78 | 높음 (3-0) | 같은 논문; Lopez-Lira & Tang (SSRN 4412788, JFE) |
| 3 | 뉴스에 늦게 반응하는 몫은 대부분 다음 실적 발표 때 나타난다. 실적 발표 후 추가 상승(PEAD)은 헤드라인이 아니라 실적 콜 내용에서 나온다 | 높음 (3-0) | Heston & Sinha 표 6; Meursault 외, JFQA 2023; Price 외, JBF 2012 |
| 4 | 관심이 많은 종목일수록 PEAD 가 약하다 | 중간 | Wang, Choi & Siraj 2018 |
| 5 | LLM 헤드라인 신호는 1~2일짜리이고 왕복 비용 20bp 에서 이익이 사라진다. 시가 체결 기준 | 높음 | Lopez-Lira & Tang |
| 6 | 뉴스 감성만으로 시장 타이밍을 하면 2bp 비용에서도 매수후보유를 못 이긴다(2005~2024) | 중간 | arXiv 2404.00012 |
| 7 | 새로운 뉴스만 거르면 Sharpe 1.03 → 1.43 | 낮음 (업체 자료) | RavenPack |
| 8 | LLM 감성이 FinBERT 보다 수익 예측력이 높다(Sharpe 3.05 대 2.07 등). 넓은 롱숏·비용 전 | 중간 | arXiv 2412.19245; Lopez-Lira & Tang |

검증에서 반박된 주장: "최근 고전적 PEAD 는 거의 0" — 인용하지 않는다.

## 우리 시스템에 대입

- 대형주 20개 + 다음 날 종가 체결이면 호재 매수로 얻을 몫이 거의 없다(1·5). 1년 백테스트에서
  실적 호재 매수가 손해 본 것과 맞다(3·4).
- 쓸 수 있는 건 악재의 느린 반영(2) — 롱 전용이면 '악재에 몇 주 빠지기'.
- 12시간 반감기는 짧다. 주간 집계(1).

## 실험 (파라미터는 논문 값 고정, 우리 데이터로 조정하지 않음)

`alpha_server/newsdesk/signals.py` 의 `NewsParams`:

| 이름 | 내용 |
|---|---|
| current | v3.4.0 (12시간 반감기, 48시간 창, 호재 매수) |
| weekly_active | 72시간 반감기·7일 창, 실적 호재 매수 끔, 중복 뉴스 제거 |
| defensive | 관심 종목 기본 보유 + 주간 악재 점수 ≤ -기준이면 4주 이탈 |
| defensive_novel | defensive + 중복 뉴스 제거 |
| hold_only | defensive 와 같은 보유, 뉴스 이탈 없음 (뉴스의 값어치를 재는 대조군) |
| defensive_static / hold_static | 위 둘에서 손실 기반 가중치(종목 손실 배수·계좌 손실 브레이크)를 끔 |

채택 기준: 상승장(2025-09~2026-09)과 하락장(2022) **두 기간 모두**에서 현재 방식보다
수익이 높고, 수익/최대낙폭도 나을 것. 뉴스의 값어치는 같은 보유 정책의 대조군과 비교한다.

LLM 해석은 유료라 이번 실험에서 뺐다.

## 판정: 채택 없음 — 기본값 유지

미리 정한 기준(두 기간 모두 current 보다 수익↑)을 통과한 변형이 없다.

각 장치의 값어치를 대조군과 비교하면:

| 장치 | 상승장 | 하락장 | 판단 |
|---|---:|---:|---|
| 악재 4주 이탈 (defensive − hold_only) | -10.9%p | +0.8%p | 손해. 논문의 비대칭은 대형주·무료 헤드라인·다음 날 체결에서 재현되지 않음 |
| 중복 뉴스 제거 | -1.5%p | 0 | 효과 없음 |
| 주간 집계 + 실적 매수 끔 (weekly_active − current) | -4.9%p | -2.4%p | 손해 |
| **손실 기반 가중치** (hold_only − hold_static) | -4.5%p | **+10.1%p** | **보호 장치로 작동**. 하락장 최대낙폭 25% → 15% |

current 의 작은 손익은 판단력보다 낮은 투자 비중(8~22%)에서 나온다. 같은 비중으로 관심 종목을
그냥 들고 있었어도 비슷하거나 나았다. 뉴스 신호 자체가 돈을 더 번다는 증거는 두 기간 어디서도 없다.
