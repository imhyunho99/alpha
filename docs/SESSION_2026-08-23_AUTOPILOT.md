# 2026-08-23 — Autopilot 구축과 모델 재검증

한 세션에서 v3.2.0(Autopilot)과 v3.3.0(공백 재생)까지 진행한 기록. 커밋 36개, 테스트 19개 → 288개.

## 무엇을 만들었나

사용자가 자본금을 넣고 **온도(1~10) 하나만** 정하면 개입 없이 굴러가는 모의 자동 운용.

설계의 축은 함수 하나다.

```python
def step(account, profile, tickers, prices, clock, journal, prob_fn, score_fn, horizon, last_rebalance)
```

시계와 가격 소스를 주입받으므로 **백테스트와 실시간이 같은 코드로 돈다.** 이 결정이 나중에 세 번 값을 했다 — 백테스트, 공백 재생, 그리고 온도별 곡선 미리보기가 전부 같은 엔진을 재사용한다.

실계좌 경로는 만들지 않았다. `autopilot/` 이 `brokers/` 를 import 하지 않는 것이 불변식이고 테스트가 강제한다.

## 왜 백테스트를 엔진의 일부로 만들었나

착수 전 기존 성능 수치를 검증했더니 쓸 수 없었다. `performance_results_v2.csv` 199종목 중 43개가 정확도 1.0인데 precision·recall 도 1.0 — 홀드아웃 마지막 20%가 통째로 상승장이라 "항상 오른다"가 다 맞은 것이었다. `backtest_data.json` 은 빈 배열이었다. 포트폴리오 수준 백테스트가 실행된 적이 없었다.

검증되지 않은 예측기에 자본의 재량권을 넘기는 기능을 만들고 있었으므로, 백테스트를 사후 검증 도구가 아니라 실행 모드로 설계했다.

## 이 레포에서 세 번 반복된 착각

전부 "모델이 좋다"로 보였고 전부 아니었다.

| | 증상 | 실제 원인 |
|---|---|---|
| 1 | 정확도 100% 43종목 | 홀드아웃 구간이 상승장 |
| 2 | 백테스트 +3,676% | 모델이 시험 기간을 학습 + 생존 편향 |
| 3 | IC 0.102 | 원시 가격 단위로 종목을 식별 |

3번이 가장 미묘했다. `SMA_20=500`(애플)과 `SMA_20=0.001`(잡코인)은 모델에게 지문이다. 거기에 섹터·산업·시총·베타가 붙으면 종목이 거의 특정된다. 정규화하고 식별 컬럼을 빼자 IC 가 0.102 → 0.049 로 반토막 났다.

## 정직한 성능 수치

`alpha_server/benchmark.py` — walk-forward 8폴드, 학습 꼬리 20일 퍼지, 시험 구간 2025-03 ~ 2026-08, 138종목.

| 후보 | IC 평균 | ICIR | 10분위 스프레드 |
|---|---:|---:|---:|
| always_up | — | — | -0.06% |
| momentum(20일) | -0.016 | -0.07 | -1.10% |
| norm13 (정규화 17→13) | 0.049 | 0.21 | +0.67% |
| current17 (원시 가격) | 0.102 | 0.48 | +2.40% |
| **voting76 (채택)** | **0.095** | 0.47 | **+2.87%** |

`norm13` 과 `voting76` 의 대비가 핵심이다. 둘 다 정규화됐는데 IC 가 0.049 vs 0.095 다. 즉 `current17` 의 0.102 는 식별이었고 `voting76` 의 0.095 는 패턴이다. **정규화된 상태로 신호를 내려면 피처가 그만큼 필요했다.**

`always_up` 과 `momentum` 을 후보에 넣은 것이 결정적이었다. 그 기준이 없었으면 IC 0.102 를 보고 "잘 된다"고 넘어갔을 것이다.

20일 지평에서 모멘텀은 **역방향**이다(평균회귀). 회전이 빠른 고온도 설정이 이 지평에서 구조적으로 불리할 수 있다.

## 모건스탠리 퀀트 모델 건

사용자가 "GitHub 에 유명한 데서 퀀트 모델을 무료로 다 풀었다"고 기억한 건 부분적으로 맞았다.

- [Lag-Llama](https://arxiv.org/pdf/2310.08278) — 모건스탠리 공동 저자, 가중치 공개. 다만 사전학습 도메인에 금융이 없고 **단변량 전용**이라 "900종목 줄 세우기"와 과제 형태가 다르다. zero-shot 주가 예측 성능이 나쁘다는 실측 보고가 있다.
- [Qlib](https://github.com/microsoft/qlib) — **사전학습 가중치를 주지 않는다.** 주는 건 팩터 정의(Alpha158/Alpha360)다.

"유명한 데서 푼 모델을 넣으면 바로 좋아진다"는 시나리오는 없었다. 대신 Qlib 의 팩터 정의를 직접 구현했다(`features_alpha158.py`, 76개, 전부 정규화).

## 고친 결함 19개

전부 원래 요청 범위 밖에서, 만들다가 드러난 것들이다.

**프로덕션에 이미 나가 있던 것**

1. **글로벌 AI 모델이 꺼져 있었다.** 저장된 피처 목록(18개)이 모델 입력(17개)과 어긋나 예측이 `KeyError: ['Date']` 로 죽고, `scoring_engine` 이 그 예외를 삼켜 AI 점수를 0으로 대체했다. **v3.1.2 의 모든 `/recommendations` 가 AI 기여 없이 나가고 있었다.** 경고는 서버 stdout 에만 찍혀 아무도 보지 못했다.
2. 오래된 CSV 91개가 yfinance 다중 헤더 잔재로 파싱 불가 — 실시간 경로도 같이 깨졌다.
3. 스테이블코인 시세 오염 (`USDE-USD` 20일 수익률 +4,799,376%).
4. `python -m alpha` 미동작 — CLAUDE.md 에 적힌 명령이 거짓이었다.

**측정을 오염시키던 것**

5. 백테스트가 최신 데이터로 예측 (look-ahead) → `signals.py` 점-시점 신호.
6. 원시 가격 피처가 모델을 종목 식별기로 만듦.
7. 10분위 스프레드가 이상치 하나에 뒤집힘 → 중앙값 기준으로.
8. 학습 타깃에서 미래 없는 행이 조용히 0(하락)으로 둔갑.

**다이얼을 무의미하게 만들던 것**

9. 온도 1이 3년간 0거래 (도달 불가능한 문턱 + ETF 티어에 채권 부재).
10. 온도를 올려도 코인이 유니버스에 안 들어감 (티어 순서대로 자름).
11. `medium` horizon 이 모델로 해석되지 않아 자동 운용이 **영원히 아무것도 못 삼**.

**실행을 불가능하게 만들던 것**

12. 모델을 호출마다 11MB 재로드.
13. 실시간 가격 조회 4.1분 (루프 주기 5분).
14. 기동 시 대량 다운로드가 네트워크 독점.
15. `update_all_data_with_progress` 가 별개 코드로 남아 순차 다운로드 + 저장 안 함.
16. 메타데이터를 종목당 왕복 + 중간 저장 없음.
17. 서버 재시작 시 자동 운용이 조용히 멈춤.
18. 라이브 루프에 로그 전무.
19. 테스트 스텁이 실제 계약보다 좁음.

## 배운 것

**같은 일을 하는 코드가 둘이면 하나만 고치게 된다.** 세 번 당했다: `update_all_data` vs `update_all_data_with_progress`, horizon 매핑이 `signals.py` 에만 있던 것, `LivePrices.get` 과 `get_many` 의 배치 여부.

**단위 테스트가 다 통과해도 통합 지점은 깨져 있을 수 있다.** 288개가 전부 녹색인 상태에서 자동 운용이 영원히 아무것도 못 사고 있었다. 백테스트는 다른 경로를 타서 멀쩡했다.

**로그가 없으면 진단이 불가능하다.** 앱 실행 후 잡은 결함 7개 중 5개가 라이브 루프에 계측을 넣은 뒤에 드러났다. 계좌가 비어 있는 것만으로는 "살 게 없었다"와 "안 돌았다"를 구분할 수 없다.

**주기는 모델 지평에 맞춰야 한다.** 20영업일을 예측하는 모델을 5분마다 물어보고 있었고, 그 대가로 "맥을 한 달 내내 켜두라"는 요구가 됐다. 1시간으로 낮추고 공백을 재생하는 쪽이 옳았다.

## 한 달 뒤 볼 것

수익률만 보면 시장이 오르면 다 좋아 보인다. 셋을 보라.

1. **세 계좌의 상대 순위** — 온도가 높을수록 정말 더 벌었나, 더 흔들리기만 했나
2. **MDD 가 백테스트 예측과 맞았나** — 수익 눈금은 못 믿지만 위험 눈금은 기계적이다
3. **`hours_since_tracked`** — 계좌별 가동 공백. 크게 다르면 수익률 비교가 무의미하다

백테스트의 +4,395% 는 잊어도 된다. 모델이 답을 아는 상태로 푼 시험이다. 정직한 기대치는 **IC 0.095, 10분위 스프레드 +2.87%** 이고, 여기서 매매마다 수수료 0.1% + 슬리피지 0.05% 가 빠진다.

## 다음에 손댈 만한 것

- `short` 모델(AUC 0.500)은 사실상 무의미하다. `/recommendations` 의 단기 점수가 그걸 쓰고 있다.
- 백테스트가 여전히 train-on-test 다. 정직하게 하려면 시작 시점 이전 데이터로만 학습한 모델로 walk-forward 백테스트를 해야 한다.
- 유니버스가 오늘 기준 구성이라 생존 편향이 있다. 시점별 구성 이력이 필요하다.
- 재생 해상도가 시간봉이라 그 안의 장중 움직임은 못 잡는다.
