# 최신 AI 투자 모델 도입 검토 (2026-10-04)

사용자가 제안받은 세 계열(시계열 트랜스포머, 심층 강화학습, LLM 에이전트)을 이 시스템에 넣을 가치가
있는지 판단했다. 기준은 "우리 조건(일봉, 대형주·ETF·코인, 개인 계좌, 수수료 포함)에서 지금 것보다
돈을 더 버는 근거가 있는가"다.

## 결론

| 계열 | 판단 | 이유 |
|---|---|---|
| 시계열 트랜스포머 (TFT, PatchTST, FEDformer) | **도입 안 함** | 같은 데이터·같은 평가에서 트리 모델보다 낮다 |
| 심층 강화학습 (PPO 등) | **도입 안 함** | 비용 차감 후 표본 외 수익이 신뢰할 만하게 입증되지 않았다 |
| LLM 에이전트 (뉴스 해석 + 규칙 집행) | **구조는 이미 있음, LLM 해석만 보류** | 뉴스 데스크가 이 구조다. 해석기를 LLM 으로 바꾸는 건 유료이고 우리 조건에서 이득 미입증 |

대신 학습이 없는 **규칙 기반 팩터 전략**(모멘텀·저변동성·추세 필터)을 모델 계좌 후보로 판정한다
(`alpha_server/autopilot/factors.py`, 결과는 아래).

## 근거

### 트랜스포머
Microsoft Qlib 공개 벤치마크(Alpha158, CSI300, 같은 데이터·같은 백테스트):

| 모델 | IC | 연 초과수익 |
|---|---:|---:|
| LightGBM | 0.045 | 9.0% |
| XGBoost | 0.050 | 7.8% |
| DoubleEnsemble (최고) | 0.052 | 11.6% |
| LSTM | 0.032 | 3.8% |
| Transformer | 0.026 | 2.7% |

우리 모델(Alpha158 류 76피처 + RF/XGB/LGBM 보팅)은 정직하게 다시 잰 IC 0.049 로 이미 같은 천장에 있다.
트랜스포머가 이 천장을 넘는다는 공개 비교는 찾지 못했고, 일봉 주가에서는 오히려 낮다. 붙여주신 글의
"가장 뛰어난 정확도"는 출처가 외환 장기 예측·전력 수요 예측 등 다른 문제다.

### 강화학습
FinRL(가장 큰 오픈소스 금융 RL) 저자들도 세 가지 장벽을 명시한다: 낮은 신호 대 잡음비, 생존 편향,
백테스트 과적합. RL 은 하이퍼파라미터 조합이 수천 개라 검증 구간 하나에 맞춰지기 쉽고, 비용 차감 후
표본 외에서 꾸준히 이긴다는 재현된 결과가 없다. 붙여주신 글이 권한 "데이트레이딩·선물 변동성"은 이
시스템의 대상(일봉, 개인 계좌)과도 다르다.

### LLM 에이전트
글의 두 번째 주의사항("예측과 주문 집행 분리, 손절은 하드코딩 규칙")은 이 시스템이 이미 하는 방식이다
(뉴스 데스크 → 엔진 규칙 → risk_manager → 감사 로그 → 증권사 연동 dry_run). 남은 선택은 뉴스 해석기를
FinBERT 에서 LLM 으로 바꾸는 것인데, 2026-09 조사에서 LLM 헤드라인 신호는 1~2일짜리이고 왕복 20bp 에서
이익이 사라졌다(Lopez-Lira & Tang). 우리 실험에서 뉴스 타이밍 자체가 두 기간 모두 보유를 이기지 못했다.
해석기만 바꿔서는 이 결과가 뒤집힐 근거가 없다.
